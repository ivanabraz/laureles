# Textos e imágenes

Laura edita cada sección del sitio en el admin. Fotos y textos de esa sección están en la misma pantalla, con pestañas **Español** y **English**.

**Admin:** https://laureles.netlify.app/admin/

Guía para Laura: [cms-laura.md](./cms-laura.md). Setup técnico: [cms-setup.md](./cms-setup.md).

## Secciones

Inicio, Sobre mí, Portfolio, Paquetes, Contacto, Aviso y promo, Menú y pie.

En Paquetes, el título y la descripción se editan dentro de cada card.
